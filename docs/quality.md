# PinFlik Download Quality

## Quality philosophy

PinFlik's quality goal is to preserve the best source media available rather than artificially inflate lower-quality files.

The live website currently describes support for:

- 720p;
- 1080p;
- 2K when available;
- 4K when available;
- original-resolution images where supported.

## Important quality principle

**Available source quality is the upper bound.**

If Pinterest provides a video at 720p, a downloader cannot create genuine 1080p or 4K detail simply by changing the output label.

PinFlik therefore emphasizes source-aware quality handling.

## What affects download quality?

Quality can depend on:

- the original upload;
- Pinterest's available media variants;
- source encoding;
- current Pinterest delivery behavior;
- browser/network conditions;
- media type.

## Quality expectations

Users should expect the highest supported quality available for the source rather than an artificial enhancement.

## Performance vs quality

The product aims to improve speed without compromising reliable media retrieval. Faster processing is useful only when the resulting media remains accurate and usable.
