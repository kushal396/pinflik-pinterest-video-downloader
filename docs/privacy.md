# Privacy

## Public product position

PinFlik's public website states that no registration is required, Pinterest login credentials are not requested, and the service is designed around a privacy-first experience.

The site also states that PinFlik does not host or store Pinterest media files on its own servers.

## Privacy principles

### Data minimization

Collect only what is necessary for the service to operate.

### No Pinterest credentials

The downloader should never require a user's Pinterest password.

### Clear communication

Users should understand what information is collected and why.

### Security by default

Transport security and secure operational practices should be maintained as the product evolves.

## Important note

This repository is product documentation, not a replacement for the live Privacy Policy.

Always refer to the current privacy policy on the live PinFlik website for legally operative details.
