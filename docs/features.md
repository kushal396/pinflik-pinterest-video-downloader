# PinFlik Features

## Core features

### Pinterest video downloading

PinFlik is designed to retrieve supported Pinterest video media for local saving.

### Pinterest Reel and Idea Pin support

The product provides a dedicated experience for supported Pinterest Reels and Idea Pins.

### Pinterest image downloading

Supported Pinterest images can be saved at the best available source resolution.

### Pinterest GIF downloading

Supported animated media can be saved using the available compatible format.

### Carousel support

The product has added support for Pinterest image carousels where supported.

### WebP support

The product has added support for high-resolution WebP images from newer Pinterest Pins.

### Quality selection

The product can expose available quality options, including HD and higher resolutions when the original source provides them.

### MP4 support

Supported Pinterest video content can be saved in MP4 format.

### Browser-based experience

No desktop application is required for the core web workflow.

### No Pinterest login

The product does not require users to submit Pinterest credentials.

### Mobile and desktop

The website is designed for modern mobile and desktop browsers.
