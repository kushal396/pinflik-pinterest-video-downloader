# PinFlik Mission

PinFlik's describes its mission as providing a seamless and user-friendly way for people to download and save Pinterest images and videos without complications.

## Mission pillars

### Simplicity

A first-time user should understand the basic workflow immediately.

### Accessibility

The core web experience should work across common modern devices and browsers.

### Quality

The product should expose the best source quality that is actually available.

### Reliability

The downloader should evolve with changes in Pinterest formats and delivery behavior.

### Privacy

The product should minimize unnecessary collection and avoid requiring Pinterest credentials.

### Responsibility

Technical capability should never be presented as permission to infringe copyright or bypass access controls.
